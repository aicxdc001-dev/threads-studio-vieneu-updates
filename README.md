# Threads Studio – VieNeu

Kênh phân phối bản cập nhật chính thức qua GitHub Releases.

## Khách hàng cập nhật tool

**Đang dùng VieNeu 2.1.0–2.1.2:** tải [gói bật Auto Update 2.1.4](https://github.com/aicxdc001-dev/threads-studio-vieneu-updates/releases/download/v2.1.4/ThreadsStudio-Bat-AutoUpdate-2.1.4.exe). Hoàn tất tác vụ và đóng tool, mở gói cập nhật, chọn đúng EXE trong thư mục bộ VieNeu đã giải nén đầy đủ rồi bấm **Cập nhật Threads Studio**. Dữ liệu, key và thiết lập đã lưu được giữ tại chỗ. Gói này dùng cho bộ VieNeu có sẵn tài nguyên.

**Đã dùng bản có Auto Update:** mở tool để tự kiểm tra, hoặc vào **Tùy chọn → Kiểm tra cập nhật**. Khi có thông báo, xem nội dung thay đổi rồi bấm **Cập nhật ngay**.

Khách chỉ cần Internet, **không cần tài khoản GitHub và không cần API key để cập nhật**.

- Kiểm tra/tải trong nền, có tiến trình.
- Xác minh SHA-256 trước khi cài.
- Sao lưu và khôi phục nếu cập nhật hoặc khởi động bản mới thất bại.
- Cập nhật chương trình, giữ dữ liệu khách và tài nguyên đã có.
