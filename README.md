# Threads Studio – VieNeu

Kênh cập nhật chính thức cho Threads Studio trên Windows 64-bit.

Ứng dụng kiểm tra bản mới trong nền. Khách hàng không cần đăng nhập GitHub hay nhập API key để tải cập nhật. Mỗi tệp được kiểm tra SHA-256; chương trình sao lưu bản cũ và khôi phục khi cập nhật hoặc khởi động bản mới thất bại.

Các tệp trong Releases là bản cập nhật cho bộ tool đã cài đầy đủ. Không bao gồm lại Chromium, bộ giọng VieNeu hoặc dữ liệu cá nhân.

Chỉ cập nhật chương trình và thông tin phiên bản. Dữ liệu, thiết lập, key bản quyền và video đã tạo được giữ nguyên.

Thông báo giấy phép của thư viện đi kèm được cung cấp trong tệp THIRD-PARTY-NOTICES.zip của Release.

Không đăng Session ID, API key, thư mục data hoặc công cụ quản lý key vào repo này.
